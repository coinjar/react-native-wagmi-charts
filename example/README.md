# react-native-wagmi-charts Example Project 🧑‍🏫

An example app to demo the usage of the Candlestick and Line charts.

The charts in this example use hardcoded data, stored in the `src/data`
directory. `src/data.ts` derives the extra variations from it — reversed,
irregularly spaced, and so on.

## Getting Started

First install project dependencies in this directory (`pnpm` is recommended):

```bash
pnpm install
```

Then go ahead and run the project on either a simulator, or a real device using
one of the following commands.

```bash
pnpm run ios
# or
pnpm run android
# or
pnpm run web
# or (if you have Expo Go installed already)
pnpm run native
```

Alternatively, you can use npm:

```bash
npm install
npm run ios     # or android, web, native
```

The above can also be done from the repository root:

```bash
pnpm install
pnpm run example:native    # or example:web
```
